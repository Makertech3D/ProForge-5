# ProForge 5 — PrusaSlicer Config Bundle

This config bundle provides ready-to-use profiles for the ProForge 5 in PrusaSlicer, including printer settings, filament profiles, and start G-code optimised for the ProForge 5 toolchanger.

**Included profiles:**
- Printer: `ProForge 5`
- Print: `ProForge Default`
- Filaments: `PLA`, `ABS`

> **Note:** PrusaSlicer 2.9.4 or later is required.

---

## Importing the Config Bundle

1. Open PrusaSlicer
2. Go to **File → Import → Import Config Bundle...**
3. Navigate to and select `P5_PrusaSlicer_config_bundle.ini`
4. Click **Open** — the profiles will be imported automatically

---

## Selecting the Profiles

After importing, select the ProForge 5 profiles from the right-hand panel:

1. Set **Printer** to `ProForge 5`
2. Set **Print settings** to `ProForge Default`
3. Set **Filament** to your desired material (`PLA` or `ABS`)

---

## After Importing

- Go to **Printer Settings → General** and confirm the **Host** field shows the correct address for your ProForge 5 (default: `proforge5.local`)
- If you have updated your printer's hostname, update this field accordingly
